# 测试说明

本项目的自动化测试位于 `tests/` 目录，采用 **pytest** 组织，聚焦纯逻辑层（不依赖网络、LLM 与数据库），保证离线可复现。测试是「系统完整性与稳定性」「测试/鲁棒性/可维护性」两项评分维度的重要支撑材料。

## 一、运行方式

```bash
# 安装测试依赖（pytest 已包含在 requirements.txt 中）
pip install pytest

# 运行全部测试
python -m pytest

# 查看每个测试用例明细
python -m pytest -v

# 运行单个测试文件
python -m pytest tests/test_citation_processor.py
```

在 Windows 控制台下建议前置 `PYTHONUTF8=1` 以规避 GBK 编码问题；`tests/conftest.py` 已内置 stdout/stderr 的 UTF-8 重配置，通常无需额外处理。

## 二、测试覆盖范围

| 测试文件 | 覆盖模块 | 验证要点 |
|----------|----------|----------|
| `test_config.py` | `nexus/config.py` | LLM/SymPas 配置默认值、环境变量覆盖、端点占位符解析、合规模式开关 |
| `test_citation_processor.py` | `nexus/cang/citation_processor.py` | 引用角标提取（`[1]`/`[证据1]`/`[Evidence 2]`）、虚构引用拒答、引用闭环校验、引用卡片渲染 |
| `test_scenario_templates.py` | `nexus/cang/scenario_templates.py` | 三大场景 DAG 结构、DAG↔低代码互转、条件表达式解析/序列化往返 |
| `test_seed_data.py` | `nexus/cang/seed_data.py` | 种子知识库字段完整性、STIX 2.1 导出、去品牌化回归、MISP Feed |
| `test_rag_refusal.py` | `nexus/cang/security_rag.py` | 低分/证据不足拒答、最低引用数门控、chunk_overlap 参数守卫 |
| `test_cangjie_client.py` | `nexus/adapters/cangjie_engine_client.py` | 引擎常量、启动缓存、DAG 规划响应解析、不可用时的 Python 降级回退 |
| `test_superagent.py` | `nexus/cang/superagent.py` | 哈希链签名链一致性、CoT 步骤追踪 |

## 三、测试设计原则

1. **确定性**：所有断言均为确定性的值/结构比对，不依赖真实 LLM 输出、外网或随机性。
2. **隔离性**：通过 `monkeypatch` 隔离环境变量与外部副作用（如仓颉引擎进程、HTTP 请求），测试结束后自动还原。
3. **真实断言**：采用 `assert` 而非 `print`，覆盖关键安全逻辑（拒答、引用闭环、降级回退）的正常与异常分支。
4. **回归护栏**：`test_seed_data.py` 内置去品牌化回归用例，防止品牌残留再次引入。

## 四、与评分维度的对应关系

- **测试/鲁棒性/可维护性**：pytest 套件 + 降级回退测试（仓颉引擎不可用时回退 Python）+ 参数守卫测试。
- **系统完整性与稳定性**：拒答/引用闭环/场景模板等核心逻辑的边界测试，保障系统在证据不足、引擎离线等异常状态下仍稳定运行。
