# 项目说明文档

## 一、项目概况

| 项目 | 内容 |
|------|------|
| 项目名称 | 鉴真智能体（CangSight） |
| 参赛赛道 | 2026「仓颉杯」智能编程大赛 · 综合系统类 |
| 项目主题 | AI + 安全大模型平台的智能体研究 |
| 一句话简介 | 以「证据锚定 RAG + 可验证 CoT + ReAct 零干预闭环」为核心的安全运营超级智能体 |

「鉴真」取「鉴别真伪」之意，对标安全运营中「幻觉防控」与「可追溯决策」两大痛点：大模型在安全研判场景下既不能凭印象臆断，也不能在处置高危动作时缺乏留痕。本系统通过引用闭环、可验证推理链与人类审批网关，构建了一条从告警输入到处置审计的完整闭环。

## 二、项目背景与问题

安全运营中心（SOC）面临海量告警、研判人力不足、处置动作风险高等现实问题。通用大模型直接用于安全研判存在三类短板：

1. **幻觉风险**：大模型可能生成不存在的漏洞编号、引用或处置建议，在安全场景下会直接导致误判。
2. **不可追溯**：常规对话式输出缺乏可复核的推理依据，难以审计。
3. **高危动作无护栏**：直接执行隔离、封禁等操作风险高，缺乏人机协同机制。

本项目针对上述问题，设计并实现了一套可落地、可复现、可审计的安全运营超级智能体。

## 四、核心能力

### 1. 证据锚定 RAG（防幻觉）

- 检索 + 重排 + 引用闭环：每条结论必须锚定可引用的来源片段。
- 低分拒答：引用置信度不足时显式降级拒答，而非静默生成。
- 离线种子知识库（ATT&CK 技战术 / CWE / 监管要点）支撑可复现评测。

### 2. 可验证 CoT（可追溯推理）

- 链式推理每一步都有明确的中间结论与依据，关键步骤可复核。
- 结合 Digest 链签名，保证推理链在审计中不可篡改。

### 3. OODA 决策循环 + ReAct 零干预闭环

- 观察（Observe）→ 判断（Orient）→ 决策（Decide）→ 行动（Act）的 9 阶段安全事件闭环。
- 工具调用与推理交替，最终输出可执行的处置建议。

### 4. HITL 人机协同 + EAT 审计链

- 高危动作（隔离、封禁等）强制人工审批。
- 全流程可追溯的安全审计（Every Action Traceable）。

### 5. 仓颉语言（Cangjie）DAG 规划引擎

- 使用华为仓颉语言编写 DAG 任务规划引擎，对安全处置流程做拓扑排序与并行度计算。
- 通过独立 HTTP 服务（端口 2270）与主系统解耦，Python 侧提供自动启动/降级回退客户端。
- 引擎不可用时自动回退到 Python 实现，保证系统鲁棒性。

### 6. XDR 平台集成

- Wazuh 深度集成（Manager REST API + Indexer 告警库）。
- 通用 REST 客户端覆盖 Splunk / Elastic / Sentinel / QRadar / 阿里云 / 华为云，统一告警字段映射。

## 六、创新点与亮点

1. **防幻觉锚定**：把「引用闭环 + 低分拒答」从研究概念落地为可运行、可评测的工程实现。
2. **仓颉语言落地**：在智能体的 DAG 规划关键路径上使用国产仓颉语言，体现新编程语言在 AI 工程中的应用价值。
3. **零干预 + 人机协同平衡**：常规研判全自动，高危处置强制人工，兼顾效率与安全。
4. **降级能力**：内置官方样本回放，不依赖外网即可完成现场演示与录屏。
