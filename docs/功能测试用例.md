# CangSight 功能测试用例清单

> 用途：比赛演示前逐项验收。
> 访问地址：外网 `http://YOUR_SERVER_IP:7800/frontend/dashboard/`（需华为云安全组放行 7800），本地 `http://localhost:7800/frontend/dashboard/`。
> 每条用例格式：**前置条件 → 操作步骤 → 预期结果**。

---

## 0. 全局

### 0.1 服务健康与连接状态
- 前置：服务 `cangsight` 已启动（`systemctl is-active cangsight` = active）。
- 步骤：浏览器打开 dashboard，看右上角连接状态按钮；或 `curl http://127.0.0.1:7800/health`。
- 预期：状态显示「在线」；`/health` 返回 `{"status":"ok","skills":84,"cwe_kb_entries":50,"rag_collection_chunks":1505,...}`。

### 0.2 深色模式切换
- 步骤：点击右上角「深色模式」按钮。
- 预期：页面配色切换到深色主题，再点恢复。

---

## 1. 首页 & 能力工作台

### 1.1 首页入口跳转
- 步骤：首页点击「能力工作台」和「过程展示」两个 portal 入口。
- 预期：分别跳到对应视图，导航标题随之变化（`route-heading` 更新）。

### 1.2 工作台能力卡片跳转
- 步骤：工作台依次点 6 张卡片（XDR 监测 / 安全对话 / CTF 攻防 / 威胁分析 / 代码扫描 / CWE 知识库）。
- 预期：6 张卡片均跳转到「能力工作台」对应 lab 并自动激活该 lab 标签。

---

## 2. 过程展示（judge / 智能体演示）

### 2.1 自定义场景输入 → 智能体生成
- 步骤：在过程展示页文本框粘贴一段告警描述（如「内网服务器凌晨检测到 lsass_backup.exe 异常进程，疑似凭据窃取」），点「智能体生成演示」。
- 预期：右侧案件区加载出与该描述匹配的模板（`templateKey=credential_theft`），标题/9 阶段/证据随之刷新。

### 2.2 八个预设场景（独立文案）
- 步骤：展开「预设场景库」，依次点 8 个卡片：SQL 注入 / WebShell 写入 / APT 入侵 / 凭据窃取 / XSS / 勒索 / DDoS / 钓鱼。
- 预期：8 个场景各自展示**不同的**案件标题、摘要、9 阶段进度条标签与「智能体动作链」文案，不再雷同：

| 场景 | 预期案件标题 | 进度条标签示例（阶段1） | 动作链含 CWE/战术 |
|---|---|---|---|
| SQL 注入 | SQL 注入攻击闭环 | 发现注入 | CWE-89 |
| WebShell 写入 | WebShell 写入攻击闭环 | 发现木马 | CWE-94 |
| APT 入侵 | APT 持续入侵攻击闭环 | 发现横移 | TA0008/持久化 |
| 凭据窃取 | 凭据窃取攻击闭环 | 发现窃取 | CWE-522 |
| XSS | XSS 跨站脚本攻击闭环 | 发现XSS | CWE-79 |
| 勒索 | 勒索软件攻击闭环 | 发现加密 | TA0040 |
| DDoS | DDoS 拒绝服务攻击闭环 | 发现攻击 | CWE-400/TA0040 |
| 钓鱼 | 钓鱼邮件攻击闭环 | 发现钓鱼 | CWE-1566/1635 |

### 2.3 九阶段回放控制
- 步骤：加载任一场景后，依次点「下一步」推进 9 个阶段，再点「上一步」「自动播放」「重新开始」。
- 预期：9 阶段按 `发现 → 关联 → 研判 → 等待审批 → 已批准 → 执行 → 复测 → 闭环` 推进；进度条标签随阶段刷新；「重新开始」回到阶段 0 并重置标签为默认文案。

### 2.4 智能体动作链（ReAct）面板
- 步骤：在「过程展示」右侧「研判与人类控制」栏，观察每个阶段新增的「智能体动作链（ReAct）」区块。
- 预期：每个阶段显示 2~4 条动作，含类型图标（💭思考 / 🔧工具 / 📚证据 / 🧠推理 / 👤审批 / ✅复测）+ 动作名 + 明细；随「下一步」切换阶段而刷新。

### 2.5 动态攻防拓扑
- 步骤：观察过程展示页的「动态攻防拓扑」区，随阶段推进。
- 预期：拓扑节点/连边随阶段状态（active/complete）高亮变化。

### 2.6 研判与人类控制
- 步骤：观察「研判与人类控制」栏的 AI 置信度、研判结论与审批按钮；在等待审批阶段点「审核真实请求」/「批准」。
- 预期：置信度数字与文案随场景/阶段变化；审批通过后阶段进入「已批准」。

### 2.7 读取本地实时
- 步骤：点击「读取本地实时」按钮。
- 预期：从本地运行态拉取真实运行/审批数据并同步到展示（无数据时给出空态提示，不报错）。

## 3. XDR 实时监测

### 3.1 启动 / 停止监测
- 步骤：进入「XDR 实时监测」，点「启动监测」；再次点切换为停止。
- 预期：按钮文案在「启动/停止监测」间切换；未配置 Wazuh 时给出「前往设置配置」引导。

### 3.2 刷新告警列表
- 步骤：点「立即刷新」。
- 预期：告警列表从 `/integrations/xdr/alerts` 刷新；无告警显示空态，不报错。

### 3.3 告警详情与统一队列
- 步骤：点任一告警查看详情；观察「统一告警 + 研判 FIFO 队列」区。
- 预期：详情命中 `/integrations/xdr/alerts/<id>`；统一队列按队首最新排序。

### 3.4 告警分析 + 处置（HITL 闭环）
- 步骤：点「批量分析」触发 `/integrations/xdr/analyze`；对高危告警点「处置」。
- 预期：分析结果进入最近分析列表；处置请求进入 HITL 待审批（见 §8），批准后才下发 block_ip/isolate。

---

## 4. 能力工作台（6 个 lab）

### 4.1 智能对话（chat）
- 步骤：进入「安全对话」lab，输入「分析这条 WebShell 告警并说明需要补充哪些证据」，点「发送分析」。
- 预期：SSE 流式返回，先 `meta` 再逐字 `delta` 输出，末尾 `done`；若启用了工具调用会展示 `tools` 事件。

### 4.2 CTF 攻防（ctf）
- 步骤：勾选「授权确认」复选框，粘贴题目描述，点「开始 CTF 分析」。
- 预期：未勾选授权时按钮禁用；勾选后提交，报告区分「模型分析 / 工具调用 / 实际返回」。

### 4.3 威胁分析（threat）
- 步骤：输入「WAF 检测到未授权文件写入，随后主机异常外联」，点「创建分析任务」。
- 预期：走 `/agents/runs` 创建运行，展示威胁研判结果（含严重度评分）。

### 4.4 代码扫描（code）
- 步骤：粘贴一段含 SQL 注入的代码（如 `query = "SELECT * FROM u WHERE id=" + uid`），点「开始扫描」。
- 预期：调用 SymPas `code_scan`，返回漏洞点列表（危险点高亮 + 严重度等级）。

### 4.5 CWE 知识库（cwe）
- 步骤：搜索「SQL 注入」或「CWE-89」，点列表条目。
- 预期：左栏列出匹配条目，右栏显示漏洞描述、严重度与修复建议。

### 4.6 OODA 调试台（ooda）
- 步骤：保留默认目标，点「运行循环」与「单步执行」。
- 预期：Observe/Orient/Decide/Act 四格依次填充，「已完成循环」计数递增；「重置」清空。

---

## 5. OODA 决策循环（attack-chain）

### 5.1 生成攻击链
- 步骤：进入「OODA 决策循环」，输入告警描述或从「典型告警类型」下拉选择，点「生成攻击链」。
- 预期：「攻击链演进」时间线逐节点生成，同时驱动「决策事件流」与「执行回执」。

### 5.2 高危动作审批
- 步骤：演进到高危动作时，在「高危动作审批」面板点「批准执行」或「拒绝」。
- 预期：批准后继续执行并生成执行回执；拒绝后状态记为「操作员拒绝处置」。

### 5.3 自动推流 / 重置
- 步骤：点「▶ 自动推流」，再点「重置」。
- 预期：自动逐节点推流；重置后时间线回到初始空态。

---

## 6. 证据锚定 RAG

### 6.1 检索知识
- 步骤：进入「证据锚定 RAG」，输入查询（如「SQL 注入处置」），点「检索知识」。
- 预期：`/rag/query` 返回带引用的检索结果，「检索结果」区显示命中条目与 CWE 引用编号。

### 6.2 案件来源库
- 步骤：观察「案件来源」区，点查看全部（跳转 `rag-evidence`）。
- 预期：来源库展示可选的案件来源，跳转正常。

---

## 7. EAT 审计链

- 步骤：进入「EAT 审计链」视图（或直接 `GET /audit/eat/chain`）。
- 预期：展示执行回执审计链（事件类型 + 审计节点）；`GET /audit/eat/verify/<session_id>` 返回可验证性结果；`/audit/eat/export` 可导出。

---

## 8. HITL 人机协同

- 步骤：进入「HITL 人机协同」，点「刷新审批」；对某条待审批任务点「审核」，选择批准/拒绝并填理由。
- 预期：队列来自 `/gateway/hitl/approvals`；批准走 `/gateway/hitl/approve/<id>`、拒绝走 `/reject/<id>`；操作后任务从待审队列移除并反映到关联运行。

---

## 9. 审计日志（case-history）

- 步骤：进入「审计日志」，点「刷新记录」。
- 预期：运行记录表列出历史智能体运行（`/agents/runs`），含运行 ID、状态、时间。

## 10. 系统设置（connections）

### 10.1 LLM 模型设置
- 步骤：进入「系统设置」→ LLM 配置，修改 provider/model/api_key，点「测试连接」。
- 预期：`GET /llm/config` 回显当前配置；`POST /llm/test` 返回真实模型应答（deepseek-chat）。

### 10.2 XDR 集成设置
- 步骤：XDR 配置页填写 Wazuh 地址/凭证，点「测试连接」。
- 预期：`POST /integrations/xdr/test` 返回连通性结果（连不通明确报错、不重试）。

## 12. SymPas 程序分析工具

> 所有漏洞相关分析必须走 SymPas 工具（不可用本地正则伪造）；SymPas 不可达时应报错而非降级。

| 工具 | 用例步骤 | 预期 |
|---|---|---|
| code_scan | 通过「代码扫描」lab 或 `vkb_retrieve` 流程提交含漏洞代码 | 命中注入点/危险点 + 严重度，返回 SymPas 结构化结果 |
| slice | 对已命中的漏洞点做程序切片 | 返回与漏洞点相关的数据流切片 |
| SBFL | 提供失败/通过测试用例 | 返回可疑度排序的可疑语句列表 |
| vkb_retrieve | 触发证据锚定 RAG 检索 | 检索走 SymPas 通道，返回 CWE/处置基线引用 |

## 13. 后端 API 直接验证（curl）

```bash
H=http://127.0.0.1:7800

# 健康
curl -s $H/health

# 技能目录
curl -s $H/skills

# 智能体运行：创建
curl -s -X POST $H/agents/runs -H 'Content-Type: application/json' \
  -d '{"objective":"分析一条 SQL 注入告警"}'

# 智能体运行：列表 / 详情 / 事件流
curl -s $H/agents/runs
curl -s $H/agents/runs/<run_id>
curl -s -N $H/agents/runs/<run_id>/events

# 场景：8 个预设 / 关键词路由
curl -s -X POST $H/agent/scenario/preset -H 'Content-Type: application/json' -d '{"preset_key":"xss"}'
curl -s -X POST $H/agent/scenario       -H 'Content-Type: application/json' -d '{"message":"勒索软件加密"}'

# CWE 知识库
curl -s "$H/cwe/search?pattern=SQL"
curl -s "$H/cwe/mitigation/89"

# RAG
curl -s -X POST $H/rag/query -H 'Content-Type: application/json' \
  -d '{"query":"SQL 注入处置","enforce_citations":true,"top_k":6}'

# OODA
curl -s -X POST $H/agents/ooda -H 'Content-Type: application/json' \
  -d '{"objective":"分析 WebShell 告警"}'

# EAT 审计链
curl -s $H/audit/eat/chain

# HITL 待审
curl -s $H/gateway/hitl/approvals

# LLM 配置 / 测试
curl -s $H/llm/config
curl -s -X POST $H/llm/test -H 'Content-Type: application/json' -d '{}'
```

预期：上述命令均返回 200 与结构化 JSON；`/agent/scenario` 的 `templateKey` 命中正确场景（不再全部 `sqli`）；`/agent/scenario/preset` 8 个 key 标题互不相同。
