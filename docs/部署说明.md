# 华为云服务器部署说明

本文档说明如何把「鉴真」智能体部署到华为云服务器（`YOUR_SERVER_IP`，Ubuntu 22.04），并与服务器上已有的网站（Nginx + contractflow，占用 80 端口、后端 8000）和平共存。

## 一、部署架构

| 项 | 现有网站 contractflow | 本项目 CangSight |
|----|----------------------|------------------|
| 入口端口 | 80（Nginx） | **7800（独立端口，避开 8000）** |
| 后端端口 | 8000（绑 127.0.0.1） | 7800（绑 0.0.0.0） |
| 进程守护 | 已有 | **systemd（cangsight.service）** |
| 域名 | 无（裸 IP，未备案） | 同左，用 `http://YOUR_SERVER_IP:7800` 访问 |

> 当前无可用域名（未备案），故采用**独立端口 + 安全组放行**方案，不修改现有 Nginx 配置，互不影响。

## 二、部署步骤

### 1. 上传源码

在本地（Windows）执行，把项目上传到服务器 `/opt/cangsight`：

```bash
scp -r nexus frontend skills scripts cangjie_engine requirements.txt run.py start.sh \
    root@YOUR_SERVER_IP:/opt/cangsight/
```

> 若不想传 Windows 版仓颉引擎编译产物（`.exe`/`.dll`），可省略 `cangjie_engine/bin/`，Linux 上会自动降级到 Python 实现。

### 2. 运行一键部署脚本

SSH 登录服务器后：

```bash
cd /opt/cangsight
sudo bash deploy/deploy.sh /opt/cangsight 7800 root
```

脚本会自动：创建 venv → 用华为云镜像装依赖 → 生成并启动 `cangsight.service`。

### 3. 配置 LLM key

```bash
mkdir -p /opt/cangsight/.nexus
vi /opt/cangsight/.nexus/llm_config.json
```

写入（按你实际使用的厂商改）：

```json
{ "provider": "deepseek", "api_key": "你的key", "model": "deepseek-chat", "base_url": "https://api.deepseek.com" }
```

配置后重启：`sudo systemctl restart cangsight`

### 4. 华为云安全组放行

华为云控制台 → 弹性云服务器 → 安全组 → 入方向规则 → 新增：

- 协议端口：`TCP 7800`
- 源地址：`0.0.0.0/0`（或限制为你的 IP）

### 5. 验证

```bash
sudo systemctl status cangsight          # 应为 active (running)
curl http://127.0.0.1:7800/health        # 返回 status ok
curl http://YOUR_SYMPAS_IP:6239/ui/         # 验证 SymPas 外网连通
```

浏览器访问：`http://YOUR_SERVER_IP:7800/frontend/dashboard/`

## 三、systemd 服务参考

部署脚本会自动生成，以下是等价的手动配置（`/etc/systemd/system/cangsight.service`）：

```ini
[Unit]
Description=CangSight Security Super Agent
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/cangsight
User=root
Group=root
Environment=NEXUS_PORT=7800
Environment=SYMPAS_MCP_URL=http://YOUR_SYMPAS_IP:6239
Environment=PYTHONUTF8=1
ExecStart=/opt/cangsight/venv/bin/python run.py
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

## 四、重要注意事项

1. **仓颉引擎**：`cangjie_engine/bin/` 是 Windows 编译产物（`.exe`/`.dll`），Linux 服务器上无法运行，系统会**自动降级到 Python 实现**，功能不缺失。若要在服务器上展示仓颉引擎，需用仓颉 SDK 重新编译 Linux 版产物。
2. **生产安全**：`run.py` 默认 `debug=False`（可用 `NEXUS_DEBUG=1` 临时开启调试）；服务无 HTTPS，仅建议比赛演示使用。
3. **SymPas 地址**：默认走外网 `YOUR_SYMPAS_IP:6239`；若服务器访问该地址不通，可改用内网地址，在 `cangsight.service` 里把 `SYMPAS_MCP_URL` 改为 `http://YOUR_SYMPAS_INTERNAL_IP:6239` 后 `systemctl restart cangsight`。
4. **端口冲突**：本服务用 7800，避开现有 8000；如需换端口，改 `deploy.sh` 第二个参数或 `NEXUS_PORT` 环境变量，并同步放行安全组。
