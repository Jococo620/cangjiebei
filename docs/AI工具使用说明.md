# AI 工具使用说明

## 一、使用概述

本项目在开发过程中使用了 AI 辅助编程工具（Claude Code 等）辅助代码编写、重构与文档撰写，用于提升开发效率。所有 AI 生成或辅助生成的代码均经过人工审查、测试与验证后方可纳入项目。

## 二、使用的 AI 工具

| 工具 | 用途 |
|------|------|
| Claude Code | 代码生成、重构、测试脚本编写、文档撰写、品牌术语迁移 |
| 通用 LLM 能力（DeepSeek / 通义千问等） | 系统内置的智能体推理引擎（非开发辅助工具） |

## 三、AI 辅助的具体环节

1. **代码重构与迁移**：将既有作品适配新赛道时，使用 AI 工具完成模块改名、依赖梳理与品牌无关化处理。
2. **测试脚本编写**：辅助编写 RAG、网关请求、MCP 端点等测试脚本。
3. **文档撰写**：辅助整理项目说明、README 等文档。
4. **缺陷排查**：辅助定位导入错误、路径硬编码等问题。

## 四、人工把控原则

- **正确性**：所有 AI 输出均经人工阅读、运行与验证，关键安全逻辑（如 HITL 审批、权限校验）由人工编写与复核。
- **可解释性**：AI 辅助生成的代码保留完整注释与设计说明，确保可维护。
- **合规性**：AI 使用遵循大赛「AI 工具使用说明」披露要求，如实记录。
- **原创性**：核心算法设计与架构由团队自主完成，AI 仅承担编码实现与文案整理的辅助工作。

## 五、声明

本团队如实披露上述 AI 工具使用情况，承诺不将 AI 用于任何违反大赛规则或学术诚信的用途。
