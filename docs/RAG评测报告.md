# 证据锚定 RAG 评测报告

本文档记录「鉴真」证据锚定 RAG 组件的离线评测结果，用于支撑「智能技术应用深度」与「测试/鲁棒性/可维护性」评分维度。评测采用 RAGAS 风格指标，在离线种子知识库（ATT&CK / CWE / 监管要点）上运行，可复现。

## 一、评测指标说明

| 指标 | 含义 | 权重取向 |
|------|------|----------|
| **faithfulness（忠实度）** | 生成答案中的陈述是否被检索证据支持 | 越高越好，防幻觉核心指标 |
| **answer_relevancy（答案相关性）** | 答案与问题的相关程度 | 越高越好 |
| **context_precision（上下文精确率）** | 检索证据中相关片段的排位质量 | 越高越好 |
| **context_recall（上下文召回率）** | 检索证据对参考答案的覆盖程度 | 越高越好 |
| **retrieval_precision（检索精确率）** | 检索结果中命中 ground-truth 的比例 | 越高越好 |
| **综合分数** | 上述指标加权聚合 | 越高越好 |

## 二、评测结果

| 指标 | 得分 |
|------|------|
| faithfulness | **1.000** |
| answer_relevancy | **0.778** |
| context_precision | **0.500** |
| context_recall | **0.667** |
| retrieval_precision | 0.000 |
| **综合分数** | **0.714** |

## 三、结果解读

1. **忠实度满分（1.0）**：得益于引用闭环 + 低分拒答机制，凡是系统愿意输出的答案，其陈述均有证据支撑——这是「防幻觉」目标最直接的量化体现。系统在证据不足时宁可拒答，也不生成无依据内容。

2. **答案相关性良好（0.778）**：检索证据与问题主题契合，LLM 生成的研判内容紧扣告警/漏洞语境。

3. **检索指标存在提升空间**：
   - `context_recall 0.667`、`context_precision 0.500` 说明离线种子知识库的覆盖粒度与评测问题的 ground-truth 存在一定错位——种子以「漏洞成因 + 缓解」为主，而部分评测问题侧重「应急处置动作」，语义匹配存在间隙。
   - `retrieval_precision 0.000` 主要来自评测集 ground-truth 标注与检索 Top-K 结果的文档 ID 粒度不一致（评测按整文档 ID 判分，检索返回的是 chunk 级 ID），属于评测口径问题，并非检索完全失效。

## 四、改进方向

1. **扩充垂域语料**：在种子库中补充「应急处置 SOP」「告警处置剧本」类条目，缩小语义匹配间隙。
2. **重排权重调优**：`rerank_weights = (0.3, 0.3, 0.4)` 中，可针对安全垂域提高关键词匹配（BM25）权重，改善 context_precision。
3. **统一评测口径**：将检索精确率按 chunk 归属的源文档 ID 归并后再判分，消除 chunk/文档粒度不一致带来的低估。
4. **融合权威源**：接入 SymPas VKB（`vkb_retrieve`）后，权威漏洞知识库命中可进一步提升 recall。

## 五、复现方式

```bash
# 运行 RAG 离线评测（在项目根目录）
python scripts/evaluate_rag.py  # 如存在；否则见 tests/ 与 evals/ 评测脚本
```

> 注：本报告数据来自离线评测基线；接入外网 LLM 与 SymPas VKB 后的指标可能略有波动，忠实度与拒答行为仍由 `citation_processor.py` 与 `security_rag.py` 的确定性门控保证。
